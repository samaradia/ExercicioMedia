# Cálculo de Média em Java

Projeto simples em Java que realiza o cálculo da média de três notas e exibe o resultado no console.

## 📌 Funcionalidades
- Declara três notas do tipo `double`
- Calcula a média aritmética
- Mostra o resultado na tela

## 🛠 Tecnologias utilizadas
- Java

## 🎯 Objetivo
Praticar variáveis, operadores matemáticos e saída de dados no Java.

Projeto desenvolvido para fins educacionais.
